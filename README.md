# swift-rfc-7232

> **Status: Namespace-reservation** — This package reserves the RFC 7232 namespace. RFC 7232 (HTTP/1.1 Conditional Requests) was obsoleted by RFC 9110; its conditional requests semantics are consolidated into HTTP Semantics/Caching and implemented in swift-rfc-9110. The package currently exposes only an empty `RFC_7232` namespace enum and is not independently implemented.
